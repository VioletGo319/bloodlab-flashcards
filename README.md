# BloodLab · 血液检测术语卡

1,000 张 English → 中文术语卡，含 IPA、英文朗读、9 个分类、搜索、收藏与本机学习进度。无需注册，无外部数据接口。

## 发布 GitHub Pages

仓库 Settings → Pages → Source 选择 Deploy from a branch → main → /(root) → Save。

发布完成后访问：https://violetgo319.github.io/bloodlab-flashcards/

## 学习

先看英文，再翻卡看中文。还不熟 / 记住了用于标记学习状态。

空格翻卡，左右键切换，翻卡后按 1 / 2 标记待复习 / 掌握。进度保存在当前浏览器；设备、浏览器与网站地址之间不自动同步。朗读采用系统语音，可用性因浏览器而异。

## 数据

沿用原有 cards.json 与 cards_with_ipa.csv，保留全部 1,000 条术语、中文、音标与分类。仅供词汇学习；既有术语及音标未在网页制作中逐条重新进行专业审校。

## 技术

纯静态 HTML / CSS / JavaScript。所有资源使用相对路径，可放到 GitHub Pages 项目根目录。无需构建、数据库或 API 密钥。
